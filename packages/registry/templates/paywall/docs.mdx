## Usage

```tsx
import { Paywall } from '@/components/kinetik/screens/paywall';

<Paywall
  title="Days Pro"
  plans={[
    {
      id: 'annual',
      title: 'Annual Plan',
      description: 'Save more with the annual plan.',
      price: 5.99,
      period: 'year',
      badge: 'Best value',
      trialDays: 3,
    },
    { id: 'monthly', title: 'Monthly Plan', price: 1.99, period: 'month' },
  ]}
  features={[
    { key: 'workdays', title: 'Work days countdown', body: 'Know how many workdays are left.' },
    { key: 'widgets', title: 'Home screen widgets', body: 'Your next date, always in sight.' },
  ]}
  onPurchase={(plan) => purchases.buy(plan.id)}
  onRestore={() => purchases.restore()}
  onClose={() => router.back()}
  onTerms={() => openURL(TERMS)}
  onPrivacy={() => openURL(PRIVACY)}
/>;
```

`onPurchase` may return a promise: that plan's button shows a spinner until it settles, reads "You’re all set" when it resolves and returns to normal if it rejects.

## When to use

- A dedicated upgrade screen opened from a locked feature, settings or the end of onboarding.
- Two or three plans, each explained on its own card.

## When not to use

- Before people have seen what the product does.
- With prices you have not localised: pass the store's price and `currency`, or replace the price lines with the store's formatted strings.

## Notes

- The saving chip compares each plan's monthly price with the most expensive plan and shows from 5% up.
- Features advance every `autoAdvance` seconds (default 4) and pause while someone swipes them. Pass a `visual` per feature for your own screenshots.
- Wire it to your purchase library (RevenueCat, expo-iap, …); the template does not talk to a store. Check the price and renewal wording against your store's rules.
