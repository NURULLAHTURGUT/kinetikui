## Usage

```tsx
import { CompassArc } from '@/components/kinetik/compass-arc';

<CompassArc heading={320} note="23 M" />;
```

## When to use

- Heading in hiking, sailing and flying apps.
- A small dashboard readout fed by a sensor.

## When not to use

- Navigation people depend on. It shows what you pass it and does not read a sensor.

## Notes

- `heading` can be any number. The dial always takes the short way round.
- Reading the phone's compass is up to you.
