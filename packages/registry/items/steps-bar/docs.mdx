## Usage

```tsx
import { StepsBar } from '@/components/kinetik/steps-bar';

<StepsBar steps={6317} distance="4.2 KM" climb="9 FLOORS" />;
```

## When to use

- Daily step or distance goals.
- Any single count towards a target with a bit of character.

## When not to use

- Several goals at once. Use Activity Rings.
- Counts with no target.

## Notes

- The walker stops once the goal is reached.
- The scale marks 0, half and the goal.
